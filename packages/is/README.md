# @lindorm/is

Type-guard helpers for primitives, objects, URLs, and JOSE tokens.

## Installation

```bash
npm install @lindorm/is
```

This package is ESM-only. Import it with `import` syntax from a project that supports ECMAScript modules. `isBuffer` and `isEqual` rely on the Node.js `Buffer` global, so the package targets Node.js runtimes.

## Features

- Type-predicate helpers for primitives, errors, dates, promises, classes, functions, and URLs that narrow the input inside `if` blocks.
- String-format checks for integer strings and the literal boolean strings `"true"` / `"false"`.
- `isEqual` deep equality with dedicated handling for `NaN`, `Date`, `Error`, `Buffer`, `URL`, `Set`, `Map`, arrays, plain objects, same-class instances, and circular references.
- `isEmpty` covering `null`, `undefined`, empty strings, empty arrays, plain objects with no own keys, and empty `Map`/`Set`.
- JOSE token shape checks (`isJwt`, `isJws`, `isJwe`, `isWebToken`) that decide on segment count and the header parameters the RFCs make REQUIRED. `typ` is never the discriminant.
- Every helper is a named export from a single entry point, so unused checks tree-shake out.

## Usage

```typescript
import { isArray, isEmpty, isEqual, isJwt, isUrlLike } from "@lindorm/is";

const handle = (input: unknown, cached: unknown) => {
  if (isEmpty(input)) return undefined;

  if (isArray<string>(input)) {
    return input.filter((entry) => !isEmpty(entry));
  }

  if (typeof input === "string" && isJwt(input)) {
    return input;
  }

  if (isUrlLike(input)) {
    return new URL(input as string | URL);
  }

  if (isEqual(input, cached)) {
    return cached;
  }

  return input;
};
```

## API

Every helper is exported individually from `@lindorm/is`. Helpers whose return type is `input is T` narrow the input when used in a conditional; helpers whose return type is `boolean` only report the result.

### Primitives

| Helper            | Signature                                                | Notes                                                                                                                                                                                                                           |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isArray`         | `<T>(input: any) => input is Array<T>`                   | True for arrays. The implementation also requires a truthy input, so it is equivalent to `Array.isArray` for any value an array can hold.                                                                                       |
| `isBigInt`        | `(input?: any) => input is bigint`                       | `typeof input === "bigint"`.                                                                                                                                                                                                    |
| `isBoolean`       | `(input?: any) => input is boolean`                      | `typeof input === "boolean"`.                                                                                                                                                                                                   |
| `isTrue`          | `(input?: any) => input is true`                         | Strict `=== true`.                                                                                                                                                                                                              |
| `isFalse`         | `(input?: any) => input is false`                        | Strict `=== false`.                                                                                                                                                                                                             |
| `isBooleanString` | `(input?: any) => input is string`                       | True only for the exact strings `"true"` or `"false"`.                                                                                                                                                                          |
| `isBuffer`        | `(input?: any) => input is Buffer`                       | Wraps `Buffer.isBuffer`. Node.js only.                                                                                                                                                                                          |
| `isDate`          | `(input: any) => input is Date`                          | True for `Date` instances whose `getTime()` is not `NaN`.                                                                                                                                                                       |
| `isFinite`        | `<T extends number>(input?: any) => input is T`          | A number that is neither `NaN` nor `±Infinity`.                                                                                                                                                                                 |
| `isInteger`       | `<T extends number>(input?: any) => input is T`          | A whole number. Narrower than `isFinite`: `1.5` is finite but not an integer.                                                                                                                                                   |
| `isNaN`           | `(input?: any) => input is number`                       | True only when the value is the number `NaN`.                                                                                                                                                                                   |
| `isNull`          | `(input?: any) => input is null`                         | Strict `=== null`.                                                                                                                                                                                                              |
| `isNumber`        | `<T extends number>(input?: any) => input is T`          | `typeof input === "number"`. Includes `NaN` and `±Infinity`.                                                                                                                                                                    |
| `isNumberString`  | `(input?: any) => input is string`                       | Matches `^-?\d+$`. Integers only — no decimals, exponents, or whitespace.                                                                                                                                                       |
| `isString`        | `<T extends string = string>(input?: any) => input is T` | `typeof input === "string"`. `T` is constrained to `string`: narrowing to a string literal union is fine, anything else is a compile error. Membership in that union is **not** checked — that guard belongs next to the union. |
| `isUndefined`     | `(input?: any) => input is undefined`                    | Strict `=== undefined`.                                                                                                                                                                                                         |

### Objects, classes, errors, promises

| Helper         | Signature                                           | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `isClass`      | `(input: any) => boolean`                           | Heuristic: returns `true` when `constructor.toString()` (on the value or on its `prototype`, if present) starts with `"class"`. Matches both class constructors and instances of native classes such as `URL`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `isError`      | `(input: any) => input is Error`                    | A REAL Error: `instanceof Error` (subclasses included), or the `[object Error]` tag for one from another realm. Deliberately NOT duck-typed on `name` + `message` — ordinary data trips that by accident (a form field, a contact record), and a consumer acting on the answer then treats plain data as an error.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `isFunction`   | `(input?: any) => input is (...args: any[]) => any` | `typeof input === "function"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `isObject`     | `<T extends Dict = Dict>(input: any) => input is T` | A PLAIN data bag — everything it holds is reachable through `Object.entries`. Excludes `null`, arrays, and every built-in whose state is invisible to `Object.entries`: `ArrayBuffer`, `SharedArrayBuffer`, `DataView`, typed arrays (which covers `Buffer`), `Date`, `Error`, `Map`, `Promise`, `RegExp`, `Set`, `URL`, `WeakMap`, `WeakSet`, and classes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `isObjectLike` | `(input: any) => input is Record<string, any>`      | The BROAD check: any non-null `typeof === "object"` value that is not an array. Includes everything `isObject` excludes — `Buffer`, `Date`, `Error`, `URL`, `Set`, `Map`, `RegExp`, and class instances. Reach for this when you mean "an object of some kind"; reach for `isObject` when you mean "a bag of key/value data".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `isRegExp`     | `(input: any) => input is RegExp`                   | `instanceof RegExp`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `isPromise`    | `(input?: any) => input is Promise<any>`            | A REAL Promise: `instanceof Promise`, or the `[object Promise]` tag for one from another realm. Asks whether the value IS a Promise, not whether it is AWAITABLE — `await` adopts any thenable, so `{ then(){} }` is awaitable without being a Promise.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `isEmpty`      | `(input: any) => boolean`                           | True for `null`, `undefined`, an empty string, an empty array, a plain object with no own keys, or a `Map`/`Set` whose `size` is `0`. Everything else returns `false`: a buffer's "empty" would mean `byteLength`, a different enough question that answering it silently is worse than not answering, and a `WeakMap`/`WeakSet` exposes no size at all.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `isEqual`      | `(expect: any, actual: any) => boolean`             | Deep equality with explicit handling for `NaN`, `Date` (`getTime()`), `Error` (`name`/`message`), `Buffer` (`.equals`), `URL` (`.toString()`), `RegExp` (`source`/`flags`), typed arrays and `DataView`/`ArrayBuffer`/`SharedArrayBuffer` (element-wise, so `NaN` equals `NaN` and kinds sharing a byte layout stay distinct), `Set` and `Map` (values AND keys compare deeply, and each counterpart matches once), arrays, plain objects, and — last, so it never shadows a built-in — two instances of the same class, by their own enumerable keys. Objects compare by key SET, so `{ a: undefined }` and `{ b: undefined }` differ. Cycles terminate in every container: a pair already on the current path is taken as equal, and the pair is released again on the way out, so one shared reference may still match two equal counterparts. TOTAL — a detached `ArrayBuffer`, a stripped prototype or a throwing getter answers `false` instead of throwing. |

### Binary and keyed collections

Each TYPE here is excluded from `isObject` because its state is invisible to `Object.entries` —
rebuilding one key-by-key yields `{}`, silently destroying it. `isDetached` is the odd one out: it
asks about a buffer's STATE rather than its type.

| Helper                | Signature                                              | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isMap`               | `<K = any, V = any>(input: any) => input is Map<K, V>` | `instanceof Map`.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `isSet`               | `<T = any>(input: any) => input is Set<T>`             | `instanceof Set`.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `isWeakMap`           | `(input: any) => input is WeakMap<WeakKey, any>`       | `instanceof WeakMap`.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `isWeakSet`           | `(input: any) => input is WeakSet<WeakKey>`            | `instanceof WeakSet`.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `isTypedArray`        | `(input: any) => input is TypedArray`                  | `ArrayBuffer.isView` minus `DataView`. Covers `Buffer`, which IS a `Uint8Array` — so `isObject` needs no separate `Buffer` exclusion.                                                                                                                                                                                                                                                                                                                                     |
| `isDataView`          | `(input: any) => input is DataView`                    | `instanceof DataView` — the only non-typed `ArrayBuffer` view.                                                                                                                                                                                                                                                                                                                                                                                                            |
| `isArrayBuffer`       | `(input: any) => input is ArrayBuffer`                 | `instanceof ArrayBuffer`.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `isSharedArrayBuffer` | `(input?: any) => input is SharedArrayBuffer`          | `instanceof SharedArrayBuffer`, with the global guarded — it exists only in cross-origin-isolated contexts.                                                                                                                                                                                                                                                                                                                                                               |
| `isDetached`          | `(input?: any) => boolean`                             | Whether an `ArrayBuffer` has been DETACHED — its memory transferred away, so every view over it throws or reads zero. Gated on really being an `ArrayBuffer` (`instanceof`, or the `[object ArrayBuffer]` tag from another realm), so data merely carrying a `detached` field answers `false`; a `SharedArrayBuffer` answers `false` too, because shared memory cannot detach. NOT a type predicate — a live `ArrayBuffer` answers `false` and is still an `ArrayBuffer`. |

### URLs

| Helper      | Signature                                            | Notes                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isUrl`     | `(input: any) => input is URL`                       | True only for `URL` instances.                                                                                                                                                                                                                                                                                                                                |
| `isUrlLike` | `(input: any, base?: any) => input is URL \| string` | True for `URL` instances or any value that successfully parses through `new URL(input, base)`. Deliberately loose — `new URL` accepts any `scheme:value`.                                                                                                                                                                                                     |
| `isUri`     | `(input?: any) => input is string`                   | A string usable as an IDENTIFIER: a URL with an authority (`https://…`) or a URN (`urn:…`). Rejects `foo:bar`, which parses but carries no authority. Also rejects any ASCII whitespace or control character (U+0000–U+0020, U+007F), which `new URL` would silently delete or trim — the validated string must be the string you go on to store and compare. |
| `isUrn`     | `(input?: any) => input is string`                   | RFC 8141 `urn:<NID>:<NSS>`; the scheme and NID are case-insensitive. The NSS must be non-empty and free of ASCII whitespace and control characters (percent-encode them).                                                                                                                                                                                     |
| `isHttpUrl` | `(input?: any) => input is string`                   | A string a LOCATION can be derived from or fetched: `http:` or `https:` with a host. Rejects a URN and any other scheme (`ftp://example.com`), and `URL` instances. Rejects ASCII whitespace and control characters for the same reason as `isUri`; normalisation the parser does anyway (trailing slash, case, IDN, default port) is still accepted.         |

### JOSE tokens

All four helpers reject non-string input, validate the dot-separated grammar, and decode the
protected header. They decide on **segment count and the header parameters the RFCs make REQUIRED —
never on `typ`**, which RFC 7515 §4.1.9 and RFC 7519 §5.1 both make OPTIONAL. Discriminating on `typ`
misroutes every externally-issued token: most id_tokens omit it, and an RFC 9068 access token carries
`at+jwt`. They do not verify signatures, decrypt, or validate claims.

| Helper       | Signature                         | Check                                                                                                                                                                                                                                                                                                                       |
| ------------ | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isJws`      | `(input: any) => input is string` | 3 segments, header object with a string `alg`. Payload may be empty (detached content, RFC 7515 App. F) and signature may be empty (Unsecured JWS). **True for a JWT too** — a JWT IS a JWS.                                                                                                                                |
| `isJwt`      | `(input: any) => input is string` | `isJws`, **and** the payload decodes to a JSON object (RFC 7519 §7.2 step 10), **and** `typ` does not declare an opaque type (`JWS` / `JOSE` / `*+jws`). Both pieces of evidence must agree, so a lying `typ: JWT` over a non-object payload is refused, and so is a signed opaque handle whose payload happens to be JSON. |
| `isJwe`      | `(input: any) => input is string` | 5 segments, header object with a string `alg` **and** a string `enc` (RFC 7516 §4.1.2).                                                                                                                                                                                                                                     |
| `isWebToken` | `(input: any) => input is string` | `isJws` or `isJwe`.                                                                                                                                                                                                                                                                                                         |

A **detached-payload** JWS and a **Nested JWT** are both `isJws` but not `isJwt`: in the first the
claims are not on the wire, and in the second the payload is an inner compact token rather than a
claims set. These are shape guards, not an algorithm registry — `alg: "none"` is still a JWS here.
`@lindorm/aegis` layers its supported-algorithm allowlist on top.
